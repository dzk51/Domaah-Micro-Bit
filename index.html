Help & Panduan


Langkah - Langkah:

  1. Buat Project melalui menu Dashboard ("Start Project").
  2. (Jika memilih Robot/All) Gunakan D-pad untuk menggerakkan robot.
  3. (Jika memilih Sensor/All) Temperatur dan Sensor selalu diupdate secara real-time.
  4. Menu Log akan merekam segala aktivitas dan pertukaran data yang masuk ke program.
  5. Output kontrol (Slider) dapat digeser dari 0 hingga batas maksimum sesuai kebutuhan.

Tips:

  • Gunakan browser dengan kecepatan yang stabil seperti Microsoft Edge atau Google Chrome.
  • Gunakan kode perintah (Up, Down, Left, Right) untuk mempermudah pergerakan.
