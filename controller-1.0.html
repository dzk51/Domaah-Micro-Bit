📌 Langkah-langkah

  • 1. Pilih project di Dashboard (Sensor / Robot / All).
  • 2. Hubungkan Micro:bit via Bluetooth (tombol di sidebar).
  • 3. Gunakan D-pad untuk menggerakkan robot (mode Robot/All).
  • 4. Data suhu & kelembaban tampil real-time (mode Sensor/All).
  • 5. Log merekam semua komunikasi data.

💡 Tips

  • Gunakan Chrome / Edge untuk koneksi Bluetooth terbaik.
  • Pastikan Micro:bit dalam kondisi menyala dan paired.
